# Personal Portfolio

Phase 1 portfolio for AI, data, software engineering, and IT opportunities.

## Stack

Next.js App Router, TypeScript, Tailwind CSS, next-themes, and lucide-react.

## Local development

`npm install` then `npm run dev`

## Build

`npm run build`

## Structure

`app/` contains routes and metadata; `src/components/` contains layout, sections, project, and UI components; `src/data/` holds configurable portfolio content; `src/types/` contains typed models.
