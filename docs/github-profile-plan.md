# GitHub profile plan

Pin ClauseForge, IncidentPilot, MedScout, and Intelligent Network Fraud Detection System. Keep each repository factual, with a summary, status, architecture visual, limitations, verified metrics where available, stack, setup, run instructions, and portfolio link.

## Repository positioning

- **ClauseForge** — Legal AI contract intelligence research system using Qwen2.5-7B-Instruct and QLoRA with controlled evaluation, safety tooling, artifact lineage, and OOD analysis. Topics: legal-ai, nlp, qwen, qlora, llm-evaluation, contract-analysis, python.
- **IncidentPilot** — AI-assisted incident investigation and automation with controlled tools, persistent context, human approval boundaries, and auditable remediation workflows. Topics: ai-agents, incident-response, automation, human-in-the-loop, python.
- **MedScout — Clinical Research & Triage Reasoning Agent** — Research/education medical evidence agent combining PubMed retrieval, deterministic red-flag safety logic, and evidence-grounded reasoning. Topics: medical-nlp, information-retrieval, pubmed, health-information, evidence-based, python. Clearly state it is not diagnostic advice.
- **Intelligent Network Fraud Detection System** — Network traffic analysis and anomaly detection using Django, React, PyShark, Random Forest, Isolation Forest, and CICIDS2017-based models. Topics: cybersecurity, network-security, machine-learning, django, react, pyshark, anomaly-detection, cicids2017.

Each README should cover overview, problem, architecture, features/workflow, stack, limitations, setup, run instructions, and repository structure. Add safety disclaimers where relevant; never add unverified claims.
